# 需求关键词

<p>本规范中的关键词 <b>必须</b>、<b>不得</b>、<b>应当</b>、<b>不应当</b>、<b>可以</b> 按 <b>RFC 2119</b> 与 <b>RFC 8174</b>（两者合称 <b>BCP 14</b>）解释。<b>仅当写作全大写</b>时，下列词才表达规范要求；其余写法（如 should、Must、SHALL）一律只作普通叙述，读者不得据此推断一致性要求。</p>

<tr><td><b>必须</b></td><td><code>MUST</code> / <code>REQUIRED</code> / <code>SHALL</code></td><td>绝对要求；不满足即不符合本规范</td></tr>
<tr><td><b>不得</b></td><td><code>MUST NOT</code> / <code>SHALL NOT</code></td><td>绝对禁止</td></tr>

<tr><td><b>不应当</b></td><td><code>SHOULD NOT</code> / <code>NOT RECOMMENDED</code></td><td>不推荐；理由同上</td></tr>
<tr><td><b>可以</b></td><td><code>MAY</code> / <code>OPTIONAL</code></td><td>真正可选；不实现不得被判定为不符合</td></tr>
