# Requirement Keywords

<p>The key words <b>MUST</b>, <b>MUST NOT</b>, <b>SHOULD</b>, <b>SHOULD NOT</b>, and <b>MAY</b> in this specification are to be interpreted as described in <b>RFC 2119</b> and <b>RFC 8174</b> (together, <b>BCP 14</b>). Only the <b>UPPERCASE</b> forms below carry normative weight; any other spelling (should, Must, SHALL, …) is ordinary prose and imposes no conformance requirement.</p>

<div class="table-wrap">
<table>
<thead><tr><th style="white-space:nowrap">Keyword</th><th style="white-space:nowrap">Equivalent</th><th style="white-space:nowrap">Meaning</th></tr></thead>
<tbody>
<tr><td><b>MUST</b></td><td><code>REQUIRED</code> / <code>SHALL</code></td><td>An absolute requirement; failing it means non-conformance</td></tr>
<tr><td><b>MUST NOT</b></td><td><code>SHALL NOT</code></td><td>An absolute prohibition</td></tr>
<tr><td><b>SHOULD</b></td><td><code>RECOMMENDED</code></td><td>A recommendation; may be ignored only with full understanding of the implications and a stated reason</td></tr>
<tr><td><b>SHOULD NOT</b></td><td><code>NOT RECOMMENDED</code></td><td>Not recommended; same caveat as above</td></tr>
<tr><td><b>MAY</b></td><td><code>OPTIONAL</code></td><td>Truly optional; omitting it must not be treated as non-conformance</td></tr>
</tbody>
</table>
</div>

<p>Items that must be implemented in order to claim conformance are aggregated as a checklist in Chapter 18.</p>
